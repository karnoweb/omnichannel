# 13.4.1

**تاریخ:** 2026-11-28  
**نوع:** PATCH

## خلاصه

رفع JSON publication روی MySQL، پایداری CI (PHPUnit MySQL + audit)، بدون migration جدید نسبت به 13.4.0.

## اصلاح

- Castهای `content` / `metadata` — ترتیب کلید JSON پایدار روی MySQL.
- تست‌ها: `OmnichannelRefreshDatabase` روی `TestCase`؛ سناریوی legacy ارتقا در job MySQL skip (SQLite-only).

## ارتقا

از **13.4.0**:

1. `composer update karnoweb/omnichannel` به `^13.4.1` یا همان constraint `^13.4`
2. بدون `php artisan migrate` اجباری
3. تست پیشنهادی: `vendor/bin/phpunit --exclude-group redis`

جزئیات: [UPGRADING.md](../../UPGRADING.md).
