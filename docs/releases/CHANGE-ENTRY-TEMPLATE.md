# الگوی ثبت تغییر

کپی برای هر ورودی جدید قبل از انتشار.

```markdown
- شناسه تغییر: REL-CHANGE-___
- عنوان و دسته:
- رفتار قدیم و جدید:
- دلیل و تاثیر بر مصرف‌کننده:
- قراردادها/درایورها/ماژول‌های متاثر:
- سازگاری یا تغییر ناسازگار:
- تغییر config، پایگاه داده، صف و میزبان:
- اقدام ارتقا و ریسک بازگشت:
- تست اجراشده، محیط و نتیجه:
- مستندات فارسی مرتبط و شواهد:
- محدودیت یا تصمیم باز:
- وضعیت: پیشنهاد / پیاده‌شده / تاییدشده / منتشرشده
```
