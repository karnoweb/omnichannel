# شواهد Redis

روی Redis 8.8.0 واقعی و موقت، محدود به 127.0.0.1 با درگاه آزاد و ذخیره‌سازی دائمی غیرفعال، فرمان `redis-cli ping` پاسخ PONG داد. `php vendor/bin/phpunit --group redis` با کد ۰، ۴ تست و ۱۰ بررسی گذشت.

پیش‌نیاز اجرای محلی افزونه phpredis و سرویس اختصاصی آزمون است. `OMNICHANNEL_TEST_REDIS_HOST` و `OMNICHANNEL_TEST_REDIS_PORT` را به نمونه ایزوله اشاره دهید. بدون این متغیرها هر ۴ تست با skip خارج می‌شوند و PASS محسوب نمی‌شوند. کلیدها پیشوند تصادفی و زمان انقضا دارند. نمونه موقت پس از آزمون متوقف شد. کار مستقل گیت‌لب با Redis 7 تعریف شده و نتیجه اجرای آن هنوز مشاهده نشده است.

راستی‌آزمایی ۲۰۲۶-۱۱-۲۸: EnvKit Redis 8.8.0 روی 127.0.0.1:6379؛ با `Set-Item env:OMNICHANNEL_TEST_REDIS_HOST` و پورت ۶۳۷۹، چهار تست و ده بررسی با کد خروج ۰.
