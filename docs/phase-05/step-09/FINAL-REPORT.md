- نهایی‌سازی واتس‌اپ برای شناسه مفقود یا ناسازگار و شواهد ناقص، نتیجه نامعلوم می‌دهد. خطای اقلام اجازه اعلام موفقیت دسته را نمی‌دهد. بررسی‌ها فقط خواندنی‌اند.

- اجرای گیت‌لب به PHP 8.4 منتقل شد. آزمون Redis و بررسی امنیت وابستگی‌ها کارهای مستقل و اجباری‌اند.
- محدودیت‌های باقی‌مانده و شواهد در [نتایج تست](TEST-REPORT.md)، [موانع](DECISIONS-AND-BLOCKERS.md) و [پذیرش](PHASE-CLOSURE.md) ثبت شده‌اند. هش فایل قفل به‌روز شد و نسخه‌های وابستگی ثابت ماندند. حداقل PHP به 8.4.1 افزایش یافت و قالب کل مخزن اصلاح شد. نسخه بسته 13.3.1 است.
