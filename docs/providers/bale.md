## ۶.۱ شناسنامه و منابع رسمی

- **نام رسمی:** بله Bot API
- **سازمان:** پیام‌رسان بله
- **کاربرد در Omnichannel:** انتشار/کاتالوگ/پیام‌رسانی بسته به درایور
- **پورتال‌ها:** https://docs.bale.ai/ — `https://tapi.bale.ai/bot<token>/METHOD`
- **منابع اصلی:** BL-S001
