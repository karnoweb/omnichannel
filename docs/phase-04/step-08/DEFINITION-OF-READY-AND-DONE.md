# DEFINITION-OF-READY-AND-DONE

وضعیت: **پیشنهادی ۴.۸** — تصویب maintainer/مالک.

## Definition of Ready (آغاز WP)

- [ ] شناسه `WP-*` و منشأ (FR/P43/OMC)
- [ ] محدوده و غیرهدف
- [ ] معیار پذیرش قابل آزمون
- [ ] پیش‌نیاز سخت برآورده یا کار مسدود علامت‌خورده
- [ ] DECهای مسدودکننده بسته یا پذیرش ریسک
- [ ] مسئول اجرا و پذیرنده (نقش)
- [ ] محیط تست در دسترس یا محدوده به مستند/تحقیق

نقص → وضعیت **مسدود**؛ فقط تحقیق مجاز.

## Definition of Done (پایان پیاده‌سازی آینده)

- [ ] محدوده مصوب پیاده شده
- [ ] معماری و استقلال میزبان رعایت شده
- [ ] تست‌های لازم اجرا و شواهد ثبت (شامل skip/اجرا نشده)
- [ ] امنیت و سازگاری بررسی شده
- [ ] DOC فارسی: CHANGELOG، providers، ROADMAP به‌روز
- [ ] UPGRADING در صورت نیاز
- [ ] بازبینی انجام و نتیجه ثبت
- [ ] استثناءها با تصمیم معتبر

## تفاوت نوع کار

| نوع | DoD اضافی |
|-----|-----------|
| فقط مستند | لینک‌ها؛ بدون ادعای تست جدید |
| تحقیق | خروجی DEC یا providers؛ بدون کد |
| درایور | contract test + provider doc |

## تفاوت پذیرش

DoD ≠ tag ≠ Production Verified.
